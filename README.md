# De STrooperij Website

## Overview
Welcome to the De STrooperij website! This project is a comprehensive web application designed to showcase the offerings and functionalities of De STrooperij. The website is built with HTML, CSS, and JavaScript, and includes various features to enhance user experience.

## Features
- **Homepage**: A welcoming landing page with an overview of the website.
- **Image Gallery**: A collection of images showcasing the essence of De STrooperij.
- **Interactive Elements**: Functionalities to engage users, such as dynamic content loading.
- **Responsive Design**: Ensures the website is accessible and visually appealing on all devices.

## File Structure
- `app.js`: Contains the JavaScript logic for interactive functionalities.
- `index.html`: The main HTML file for the website.
- `style.css`: The CSS file for styling the website.
- `img/`: Directory containing images used on the website.
  - `old/`: Subdirectory for older images.
  - `SJ-2025/`: Subdirectory for images related to the SJ-2025 event.
  - `list.json`: JSON file containing metadata for the images.
